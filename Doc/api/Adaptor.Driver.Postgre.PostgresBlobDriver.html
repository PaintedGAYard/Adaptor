    Class PostgresBlobDriver

    PostgreSQL BLOB driver providing upload/download capabilities via the PostgreSQL Large Object API. Shares the same database schema with PostgreSqlDriver and PgVectorDriver, and participates in distributed transactions via Enlist(Transaction).

    Syntax
    public sealed class PostgresBlobDriver : ITransactionalResourceManager, IResourceManager, IBlobUploadCapability, IBlobDownloadCapability, IBlobRandomAccessCapability, IHealthCheckCapability
    Remarks

    Uses PostgreSQL built-in Large Object mechanism (lo_creat/lo_write/lo_read/lo_unlink). All LO operations are transactional and support rollback. The adaptor_blob_store mapping table is auto-created on first upload.
