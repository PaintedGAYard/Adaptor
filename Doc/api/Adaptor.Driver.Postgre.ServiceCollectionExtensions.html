    AddAdaptorPostgreDrivers(IServiceCollection, NpgsqlDataSource)

    Register all three PostgreSQL drivers using a shared Npgsql.NpgsqlDataSource. The DataSource should be configured with UseVector() for pgvector type mappings.

    Declaration
    public static IServiceCollection AddAdaptorPostgreDrivers(this IServiceCollection services, NpgsqlDataSource dataSource)
    Parameters
    Type Name Description
    IServiceCollection services
    NpgsqlDataSource dataSource
    Returns
    Type Description
    IServiceCollection
    Remarks

    Using a DataSource is the recommended approach because:

    1. It enables pgvector-dotnet type mappings via dataSourceBuilder.UseVector()
    2. It provides connection pooling managed by Npgsql
    3. It avoids repeated connection-string parsing

    Note: All three drivers share the same DataSource, but each maintains its own connection manager and transaction tracking.
