    Class BlobStreamSessionStore

    BlobStream session store managing session_token to session parameter mappings. Supports: gRPC BeginSession (create), WebSocket connect (validate/reconnect), gRPC EndSession (invalidate + close WS), and background GC for expired/paused sessions.
