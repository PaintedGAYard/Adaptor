    Namespace Adaptor.Driver.Postgre

    Classes

    NpgsqlConnectionManager

    Manages Npgsql connections and local transactions for a single driver instance. Each driver creates its own manager; the manager is not shared across drivers.

    NpgsqlConnectionManager.ConnectionEntry

    Per-transaction connection state.

    PgVectorDriver

    pgvector Vector Driver providing upsert/search capabilities via the PostgreSQL pgvector extension. Shares the same database schema with PostgreSqlDriver and participates in distributed transactions via Enlist(Transaction).

    PostgreSqlDriver

    PostgreSQL SQL driver providing Execute/Query capabilities with .NET distributed transaction support via Enlist(Transaction).

    PostgresBlobDriver

    PostgreSQL BLOB driver providing upload/download capabilities via the PostgreSQL Large Object API. Shares the same database schema with PostgreSqlDriver and PgVectorDriver, and participates in distributed transactions via Enlist(Transaction).
