    Class NpgsqlConnectionManager

    Manages Npgsql connections and local transactions for a single driver instance. Each driver creates its own manager; the manager is not shared across drivers.

    Inheritance
    object
    NpgsqlConnectionManager
    Namespace: Adaptor.Driver.Postgre
    Assembly: Adaptor.Driver.Postgre.dll
    Syntax
    public sealed class NpgsqlConnectionManager
    Remarks

    Responsibilities:

    1. Create and track Npgsql connections per .NET Transaction (via LocalIdentifier)
    2. Enlist the driver as a volatile resource manager in each transaction
    3. Provide thread-safe per-transaction locking (optional, used by the driver)
    4. Clean up all resources on dispose
