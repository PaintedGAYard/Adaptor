    Interface IBlobRandomAccessCapability

    Random-access BLOB operations with file-like Seek/Read/Write/Close semantics, orthogonal to the upload/download capabilities.

    Namespace: Adaptor.Coordinator.Abstractions
    Assembly: Adaptor.Coordinator.dll
    Syntax
    public interface IBlobRandomAccessCapability
    Remarks

    The file descriptor (loFd) is obtained from OpenAsync(string, BlobAccessMode, Transaction, CancellationToken) and used in subsequent operations.
