## Phase B-1: BlobDelete LO Cleanup

> time: [20 14:05] · status: resolved · tags: production, blob, lo-unlink

### Changes

**AdaptorService.cs** — BlobDelete now:
1. Queries OID via `IRelationalQueryCapability`: `SELECT oid FROM adaptor_blob_store WHERE key = @key`
2. If OID exists, calls `SELECT lo_unlink(@oid)` via `IRelationalExecuteCapability`
3. Deletes mapping record: `DELETE FROM adaptor_blob_store WHERE key = @key`

All steps run within the same distributed transaction (2PC). Fixed the LO storage leak previously noted as "manual".

## Phase C-2: ConnectionHandler Lifecycle Refactor

> time: [20 14:14] · status: resolved · tags: connection, lifecycle, pause

### Changes

**HandleAsync** restructured to support three disconnect semantics:

| State | Trigger | Transaction | Handles |
|:-----:|---------|:-----------:|:-------:|
| **Pause** | WS network drop / exception | Kept | Cleaned |
| **Terminate** | Client Close frame / EndSession / Timeout | Rolled back | Released |

Key logic:
1. On WS connect: checks if session has a paused transaction → reconnect path
2. Message loop: catches `WebSocketException` and general exceptions as abnormal close → pause
3. On graceful close (`message == null`): terminate → rollback
4. On cancellation (timeout/EndSession): terminate → rollback
5. Handshake now includes `reconnected` flag
